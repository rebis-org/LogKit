# Security Policy

## Supported versions

Security fixes are applied to the latest `main` branch only.

- `main`: supported
- Tags: best effort

## Reporting a vulnerability

Do not open a public issue. Report suspected vulnerabilities privately via [GitHub security advisory reporting][advisory].

[advisory]: https://github.com/rebis-org/LogKit/security/advisories/new

Include:

- A description of the issue and its potential impact
- Steps to reproduce, with a [MRE][MRE] if possible
- Affected version or commit and platform
- Any suggested mitigations or fixes

[MRE]: https://stackoverflow.com/help/minimal-reproducible-example

## Response process

1. Acknowledge reports within 7 business days.
2. Investigate and confirm the issue, then coordinate a fix and disclosure timeline with the reporter.
3. Prepare the fix privately and merge when ready.
4. Publish a [security advisory][advisories], crediting the reporter unless anonymity is requested.

[advisories]: https://github.com/rebis-org/LogKit/security/advisories
